# DocuMind AI – Frontend

Frontend application for DocuMind AI, an AI-powered document analyser that allows users to upload documents, view AI-generated summaries, and ask questions about document content.

## Features

- Upload PDF, DOCX, and TXT files.
- File type and file size validation.
- Display uploaded document information.
- Show document processing status.
- Display AI-generated document summaries.
- Interactive AI chat interface.
- Display answers and relevant sources.
- Delete the uploaded document and start a new analysis.
- Responsive user interface.

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript
- Native Fetch API

## Installation

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file in the frontend root directory.

```env
VITE_API_BASE_URL=http://localhost:5000/api/v1
```

Make sure the backend server is running and the API URL matches your backend configuration.

### 4. Start the development server

```bash
npm run dev
```

The frontend will run at:

```text
http://localhost:5173
```

## Application Workflow

### 1. Upload Document

- User selects a PDF, DOCX, or TXT file.
- Frontend validates the file type and size.
- File is sent to the backend using FormData.
- Uploaded document information is displayed immediately.

### 2. Document Processing

- Frontend polls the document status endpoint.
- Displays a processing state while the backend analyses the document.
- Updates the document information when processing completes.
- Displays an error if processing fails.

### 3. Document Summary

Once processing is completed, the frontend displays the summary generated by Gemini AI.

### 4. Ask Questions

- User enters a question in the chat interface.
- Frontend sends the document ID and question to the backend.
- Backend retrieves relevant document content and generates an answer.
- Frontend displays the answer and available sources.

### 5. Delete Document

- User clicks the delete option.
- Frontend sends a delete request to the backend.
- Uploaded document information and chat interface are cleared.
- User can upload another document.

The application uses the native Fetch API for HTTP requests.
